# Invariant StableSwap

Saber StableSwap vise les paires corrélées avec un invariant conçu pour limiter le glissement autour d’un prix proche. Le dépôt sépare le programme, les mathématiques, le client et les outils de simulation. Les calculs de courbe sont une primitive critique : arrondis, bornes et convergence influencent directement les montants.
