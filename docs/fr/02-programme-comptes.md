# Programme et comptes

Le programme Anchor conserve les pools, les autorités, les vaults et les comptes de tokens. Le client Rust fournit des liaisons pour construire les instructions sans masquer les comptes requis. Une intégration doit vérifier le program ID, les mints, les autorités et la correspondance entre état lu et instruction signée.
