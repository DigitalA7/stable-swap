# Limites et sécurité

Le parcours couvre l’invariant, les comptes, la liquidité, les swaps et la structure des clients. Le dépôt indique une licence Apache 2.0 et un audit Bramah Systems. Aucune installation, compilation ou exécution de test n’a été réalisée ; les garanties dépendent du programme déployé, du cluster, des versions clientes et des paramètres de pool.
