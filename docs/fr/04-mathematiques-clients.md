# Mathématiques et clients

Le dépôt expose une crate de mathématiques, une crate de client, des bindings Anchor et un SDK JavaScript référencé dans le README. La séparation permet de réutiliser les calculs sans confondre simulation et transaction. Les simulations de l’invariant servent de référence documentaire, mais n’ont pas été exécutées ici.
